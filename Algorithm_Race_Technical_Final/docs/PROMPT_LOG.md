# AI Prompt Log

This log documents the AI-assisted development prompts used for the Algorithm Race prototype.

1. **Project foundation:** Build a browser-only sorting algorithm race using HTML, CSS, and vanilla JavaScript. Show two algorithms side by side using the same input data, animated bars, playback controls, and live operation counters.
2. **Technical structure:** Organize the project into `index.html`, `assets/css/style.css`, `assets/js/script.js`, documentation, and a README. Keep it runnable without a backend, API key, or package installation.
3. **Advanced edition:** Add a futuristic dark-purple/cyan interface, developer telemetry, Big-O explanation, and an execution trace.
4. **Reliability and learning upgrades:** Add Selection Sort and Heap Sort, multiple input patterns, a local benchmark mode, end-of-race sorted-array validation, and a short interactive algorithm quiz. Preserve shared input data and clearly distinguish event-count race results from measured browser timing.
5. **Validation:** Check JavaScript syntax and run randomized correctness tests for all six sorting generator implementations against a numeric sorted reference.

AI was used as a development aid. The project code and test results should be reviewed by the project author, and the manual browser checklist in `PROJECT_NOTES.md` should be completed in the actual demo environment.
