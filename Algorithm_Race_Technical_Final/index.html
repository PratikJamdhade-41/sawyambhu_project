What does Big-O mean?

Growth estimates describe how work scales as input size increases; they are not direct runtime predictions.

LinearO(n)Growth proportional to input size
LinearithmicO(n log n)Common efficient comparison sorting
QuadraticO(n²)Nested comparisons can grow quickly

How to race

  1. Choose a sorting algorithm for racer A and B (six algorithms are available).
  2. Set the array size, then create a new shared dataset.
  3. Press Start race to animate both algorithms together.
  4. Use Pause or Step to inspect individual operations.
  5. Compare counters, use the Benchmark Lab for local timing, and try the quiz.

Tip: Try Bubble Sort vs Merge Sort with 100 values to make the difference more visible.
